# Installer dependency evidence

NSIS 3.11: the exact v311 source COPYING contains the zlib, bzip2 and CPL-1.0 terms, including the explicit NSIS LZMA linking exception. The unmodified source is available from the source archive URL in sources.json. Standard System/nsDialogs/StartMenu/LangDLL plug-ins use the NSIS source license unless noted. The System x86 Call.S file carries separate MIT notices; its complete original bytes are included. Modern UI 2 License.txt is not UTF-8, so its unmodified upstream Readme.html is included instead: its License section contains the complete original terms and copyright. No source notice was transcoded or shortened.

Tauri templates and nsis-tauri-utils: both upstream MIT and Apache original texts are included. The official nsis-tauri-utils 0.5.3 DLL matches the SHA-1 pinned in Tauri CLI 2.12.1. PE inspection found only kernel32.dll, advapi32.dll, user32.dll and shell32.dll imports. The plugin uses no_std, an explicit HeapAlloc allocator, and its 0.3.0 change records removal of static msvcrt; no separate Microsoft CRT DLL is supplied by this plugin. Nexa's existing Microsoft runtime license originals remain in the desktop package.

The plugin's release tag does not contain Cargo.lock (.gitignore explicitly excludes it); its release workflow uses cargo build --release without a pinned Rust toolchain. Thus the upstream DLL's exact resolved crate patch versions and compiler version are not available from published source. This inventory does not invent a release lockfile or claim a reproducible DLL build. Declared target dependency families are semver 1.x, windows-sys 0.61.2-compatible and windows-link 0.2.1-compatible; complete MIT and Apache originals from the exact crate archives identified in sources.json are supplied in addition to Nexa's own locked desktop Rust license closure. Host-only procedural macro dependencies are covered by that existing closure. Rust core/alloc notices are retained through the existing full Rust standard-library copyright and license originals; the upstream plugin compiler version is unknown.

WiX 3.14.1: complete official MS-RL original included. The exact unmodified source archive is linked in sources.json. WiX build tools are not installed as part of Nexa; MSI tables and embedded WixUIExtension code are produced by the standard Tauri WiX route.

These originals are staged into licenses/index.json and losslessly consolidated with the existing desktop license bundle. They do not add another top-level LICENSE file or discard existing application/runtime notices.
