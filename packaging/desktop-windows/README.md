# Nexa Windows x64 CPU 桌面开发包

完整解压 ZIP 后双击 `nexa-desktop.exe`。保持 `runtime/` 子目录原样，不混用其他包的 EXE、DLL 或 manifest。首次使用在模型页选择“初始化并启动”，再原生选择本地 GGUF 并导入。模型外置，本包不带模型、聊天记录或令牌。导入会在 `%LOCALAPPDATA%/Nexa` 创建受管理副本，占用额外磁盘空间。

## 先决条件与支持证据

本轮 Windows 10 优先，使用系统已安装的 **Microsoft Edge WebView2 Evergreen Runtime（x64）**。应用建立 WebView 前会实际检测；缺失时显示原生提示，用户自行从微软官方入口安装：https://developer.microsoft.com/microsoft-edge/webview2/ 。不会自动下载或安装，也不会改目录 ACL、ExecutionPolicy、Defender。安装 Edge 或操作系统版本本身不能证明 WebView2 可用。

`nexa-desktop.exe --diagnose` 只输出包身份、完整性与实际 WebView2 版本，不建窗口、不启动 runtime、不访问聊天或令牌。该诊断不等于原生窗口交互验收。

Windows Server 2022 CI、bridge 真实模型测试和实际用户 Windows 10 UI 操作是独立验证层。无开发工具、实际离线、长期稳定性和 Windows 11 按用户决定后续验证，未据此承诺已通过。CPU/2048 上下文/2 线程/128 批次是默认下一次加载偏好，不能代表本机实测性能或已有 runtime 当前参数。

## 生命周期与数据

- 默认关闭窗口会取消本窗口请求，保留独立 runtime 与其他客户端；不会靠父进程退出或 Job 杀掉 runtime
- “同时退出 runtime”与显式停止会影响全部客户端，只有服务清理确认后才显示停止；清理失败会保留窗口并提供重试/仅关界面选择
- CPU、上下文、线程、批次和输出预算为 UI 偏好；运行中的已加载参数不会被偷偷修改
- 空闲卸载配置（1–86400 秒）须先停止服务、单独保存，下次启动生效
- “复制 API 令牌”会把凭据写入系统剪贴板，可能进入系统剪贴板历史；仅供可信本机客户端使用。WebView 不接收或读取令牌
- 会话仅在当前 UI 内存保留；文本作为纯文本展示，生成失败或取消后的部分回复标记为不完整

`manifest.json` / `SHA256SUMS` 声明完整文件、原 runtime 身份与依赖闭包；哈希表示包一致性，不等于数字签名。`runtime/README.md` 保留既有 CLI 说明。请从可信的本次开发 Actions 产物获取本包。

## Windows 10 手工 UI 验收（尚需实际操作）

1. 完整解压到中文且含空格的目录，直接启动。记录实际 WebView2 版本和操作系统版本
2. 初始化/连接既有 runtime，原生选取中文含空格 GGUF，核对文件名与复制说明，导入后加载，完成一次中英文真实流式聊天
3. 生成中停止、清空、重复点击发送/关闭、切页；确认仅一个请求、部分回复标记与无重复文本
4. 默认关闭后确认可信 API 仍可调用；重新打开能连接同一服务。勾选同时退出后关闭，确认 API 失效、实例释放和 worker 清理
5. 确认缺模型、错误模型、加载失败、上下文超限、连接失败及关闭失败均有可见恢复方式；不把模拟 UI 或静态截图视为这些结果
