# Nexa Windows x64 CPU 桌面开发包

完整解压 ZIP 后双击 `nexa-desktop.exe`。保持 `runtime/` 子目录原样，不混用其他包的 EXE、DLL 或 manifest。本包不带模型、聊天记录或令牌。

在设置中选择已有 GGUF 所在目录，点击应用，等待核验完成；如果服务正在运行，先显式停止服务，程序不会自动停止其他客户端。首次使用再点“初始化并启动”，随后从模型列表加载并聊天。无需手填模型 ID，显示名默认取文件名去掉 `.gguf`，保留中文和空格。

所选目录只需可读，非递归读取直接子级 GGUF；不会复制、移动、重命名或删除源文件，也不在模型目录写索引/锁/缓存。配置、token及模型注册元数据仍在 `%LOCALAPPDATA%/Nexa`，旧版已导入的 managed 模型继续保留，不自动迁移或删除。列表同时标明 managed/external 来源。更换或修改源模型后，在服务停止时重新扫描。

可以选择程序包外任意受支持的本地普通目录，也可选择程序根目录、旁边的 `model/` 或 `models/`。包内只允许这些位置的直接普通 `.gguf`，不允许链接/重解析点、未知DLL/EXE/脚本或嵌套目录；不要放进 `runtime/` 或 `licenses/`。包启动只查四字节GGUF头，不把用户模型计入产品清单；登记与首次加载另执行完整核验。目录不可读或不支持会明确报错，不静默换回C盘。

Windows运行时为实际准备过的外部源持有只读保护，直到服务真正停止并回收worker；仅停止生成、卸载或默认关闭UI不会提前释放。替换、编辑或重命名这些源文件前，请先停止服务。设置中的“当前生效目录”来自已证明身份的运行服务，不能把刚选定的目录误认成已生效。

## 先决条件与支持证据

本轮 Windows 10 优先，使用系统已安装的 **Microsoft Edge WebView2 Evergreen Runtime（x64）**。应用建立 WebView 前会实际检测；缺失时显示原生提示，用户自行从微软官方入口安装：https://developer.microsoft.com/microsoft-edge/webview2/ 。不会自动下载或安装，也不会改目录 ACL、ExecutionPolicy、Defender。安装 Edge 或操作系统版本本身不能证明 WebView2 可用。

`nexa-desktop.exe --diagnose` 只输出包身份、完整性与实际 WebView2 版本，不建窗口、不启动 runtime、不访问聊天或令牌。该诊断不等于原生窗口交互验收。

启动校验失败时，原生提示与诊断报告会提供固定错误码，不输出用户绝对路径。请保留该代码排查；不会把所有失败都认定为解压错误。诊断 schema 2 的 `package_error_code` 在校验成功时为 null，失败时给出受控类别。

Windows Server 2022 CI、bridge 真实模型测试和实际用户 Windows 10 UI 操作是独立验证层。无开发工具、实际离线、长期稳定性和 Windows 11 按用户决定后续验证，未据此承诺已通过。CPU/2048 上下文/2 线程/128 批次是默认下一次加载偏好，不能代表本机实测性能或已有 runtime 当前参数。

## 生命周期与数据

- 默认关闭窗口会取消本窗口请求，保留独立 runtime 与其他客户端；Nexa不会创建随UI关闭而终止runtime的Job或自动杀进程句柄
- 外部宿主施加的Job或登录会话限制仍生效；不保证宿主终止整个Job/会话后runtime还存活，也不会尝试脱离这些限制
- “同时退出 runtime”与显式停止会影响全部客户端，只有服务清理确认后才显示停止；清理失败会保留窗口并提供重试/仅关界面选择
- CPU、上下文、线程、批次和输出预算为 UI 偏好；运行中的已加载参数不会被偷偷修改
- 空闲卸载配置（1–86400 秒）须先停止服务、单独保存，下次启动生效
- “复制 API 令牌”会把凭据写入系统剪贴板，可能进入系统剪贴板历史；仅供可信本机客户端使用。WebView 不接收或读取令牌
- 会话仅在当前 UI 内存保留；文本作为纯文本展示，生成失败或取消后的部分回复标记为不完整

`manifest.json` / `SHA256SUMS` 声明完整文件、原 runtime 身份与依赖闭包；哈希表示包一致性，不等于数字签名。`runtime/README.md` 保留既有 CLI 说明。请从可信的本次开发 Actions 产物获取本包。

## Windows 10 手工 UI 验收（尚需实际操作）

1. 完整解压到中文且含空格的目录，直接启动。可分别把GGUF放在程序根、model/或models/直接子级，确认不误拒；记录实际WebView2和操作系统版本
2. 服务停止时原生选择中文/空格模型目录，应用并核对自动名称、零复制说明和核验终态；启动后确认实际生效目录，加载并完成中英文真实流式聊天。旧managed模型应仍可见
3. 生成中停止、清空、重复点击发送/关闭、切页；确认仅一个请求、部分回复标记与无重复文本
4. 默认关闭后确认可信 API 仍可调用；重新打开能连接同一服务。勾选同时退出后关闭，确认 API 失效、实例释放和 worker 清理
5. 确认扫描取消、目录变动、源文件变动、加载失败、上下文超限、连接失败及关闭失败均有可见恢复方式；停止服务后源文件才可替换。模拟UI或静态截图不替代这些结果
