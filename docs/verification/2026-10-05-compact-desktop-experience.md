## 独立复核发现与修正

- 关闭脏草稿确认框仍在时，Alt 导航曾把焦点移到框外。现统一取消根层未确认弹窗再导航，未调用关闭/停止/保存；保留原有停止确认与 LAN 复制确认的快捷键取消行为，不通过删除原断言改变既有契约
- 打开详情后模型从原生列表消失，原控件及返回来源均可能卸载。现仅在身份缺失且焦点掉出控件时回退到缺失标题，返回时找不到原详情按钮则聚焦模型库标题；普通轮询不重置焦点
- 基础测试跨页完成时，原全局 notice 过滤会隐藏失败。现提供紧凑可关闭终态提示；仅当前详情已显示同一结果时去重。关闭只清除该提示，不移除活动结果；下一次相同文案失败仍重新出现
- 旧 finished passed 曾长期覆盖原生后续 stale/unavailable 或较新失败证明。现运行中仍优先中性；最新失效/不可读证明降级，较新有效时间结果优先；当前失败不被较旧通过覆盖。模型详情也使用最新证据，旧通过明确标为历史，不保留当前绿色

相关复现见独立检查目录 `/workspace/shared/nexa-compact-final-review/independent.test.tsx`。修复后独立复验 14/14 通过，退出 0；另独立重跑永久回归子集 ServiceControl / CompactExperience / ReviewRegressions 共 88/88 通过，退出 0。该 88 项属于完整 654 项，不额外相加。独立审查还核对十个被审查源文件的 SHA-256 与冻结源码一致、完整 JSON 为 654/654，确认没有剩余源码阻断。
