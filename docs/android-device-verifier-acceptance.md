# Nexa 安卓设备验证版：一加 15 首轮验收

这是独立研究验证 APK（应用名“Nexa 设备验证”），先验证固定模型的 CPU 推理与生命周期，不是完整聊天产品。最低 Android 9/API 28，仅 arm64；内部 debug 证书签名，不代表正式发行。GPU/NPU、任意模型导入和长期稳定性尚未验收。

## 1. 准备模型

从固定 [Qwen3-0.6B-MNN revision](https://huggingface.co/taobao-mnn/Qwen3-0.6B-MNN/tree/34dfccda1187ded6e07ea06426da576b0b793c6b) 下载以下五文件到手机可由系统文件选择器访问的位置（例如 Downloads 下的独立目录）：

- config.json
- llm_config.json
- llm.mnn
- llm.mnn.weight
- tokenizer.txt

总计 454,470,710 bytes。不要改名或混用其他 revision；程序逐文件核对固定大小及 SHA256，完整预期值见 [候选锁](../scripts/android_mnn/candidate-model.json)。此严格校验用于固定测试基线，不是未来所有用户模型的命名要求。

不需要 root。普通应用不能读取 MNN Chat 的私有 `/data/user/0/...` 模型缓存，“所有文件访问”权限也不会绕过该沙箱。本版本通过系统选择器读取用户选择的文件并复制到自己的受控存储，不删除源文件。导入需约 995 MiB 额外可用空间；下载源文件所占空间另计。

## 2. 安装与基本运行

1. 在手机上安装随交付提供的 APK。若系统询问安装来源权限，由用户自行决定并操作；无需启用开发者模式或连接 adb。
2. 打开“Nexa 设备验证”，等待“就绪”。若初始化失败，保留屏幕错误码反馈，不反复清空数据。
3. 点击“选择固定候选的五个文件”，在系统文件选择器中一次选齐五个文件。等待导入结束。
4. 点击“运行真实 smoke”，保持前台直到出现最终结果。看到文本不等于整套通过；同时检查最终 outcome 与 cleanup。
5. 点击“导出脱敏只读报告”，自行选择保存位置，将 JSON 文件发回本次对话。
6. 点击“运行安全用例（人工项另记未测）”，结束后再次导出该次 JSON。报告中的人工项 not_run 是如实未测，不应改成 pass。

## 3. 人工生命周期检查

自动用例完成后，再分别测试：

- 运行中点击“停止，等待安全卸载”：等待终态，确认没有继续输出；再启动一次能正常执行
- 运行中返回桌面，稍后回到 App：应请求取消并安全卸载，不自动重放；停止按钮发出请求不等于原生内核已返回
- 打开文件选择器后取消：返回 App 后仍可继续操作，不永久 busy

每次保留最终结果/错误码，异常时附截图与对应导出报告。若出现 cleanup unconfirmed，不要把再次点击或重新前台视为已恢复；报告后结束该进程，再讨论下一步。应用内“移除应用内候选副本”只移除其管理的副本，不删除 Downloads 源文件。

报告不自动上传，也不保存聊天正文、文件 URI、设备序列号或完整日志。它会包含脱敏的模型/引擎/构建、设备环境及测试结果；用户手动选择是否分享。

## 验收范围

Linux 真实链、APK 构建、签名/依赖/16KiB 静态检查不能替代本机实际测试。首次结果仅适用于这一台手机、系统版本、固定模型与 CPU 参数。后续 Android 兼容范围、GPU/OpenCL、QNN/Hexagon 和聊天功能分别推进，不由一次 CPU 通过推导。
