# ADR0021：添加选中文件，默认不自动全量扫描

日期：2026-10-04。状态：实现、本地回归与交叉编译检查完成，Windows实机与联合包待验。覆盖 ADR0019 的被动发现后自动全目录扫描安排，不代表当前用户已安装包拥有此行为。

## 用户目标与工作流

在模型页通过原生“添加模型”选择一个或多个 GGUF，仅核验并零复制登记所选文件，不因添加一个文件读取整个模型目录。打开程序、进入模型页及刷新默认只读已有索引；完整扫描改为用户明确选择的维护操作。下载成功后也只登记本次文件。

本轮新分支 `codex/nexa-add-model` 从当时最新 main `6167d07cb523cc838e6a6fb082e660d56e9d7f79` 创建，与已完成的 LAN 分支分别提交。最终联合包在相关切片完成后统一构建，不能把中间分支当成已交付版本。

## 数据与路径边界

- `model-library.json` schema2 表示有界模型登记；兼容读取 schema1。只读浏览不重写升级，明确添加/维护提交时才原子发布新版本
- 默认目录的路径、身份和ID组成完整可选三元组：必须全部存在或全部不存在；没有默认目录仍可添加和查看已选文件
- 显式单文件登记各自保留受保护的来源目录及身份，文件字段继续是严格 basename；不把任意绝对路径塞入原 `relative_file`
- 选择不同本地目录文件不会修改默认下载目录，不复制模型、不清空旧 managed 或 external 登记；新UI单独设置默认/下载目录也只配置位置，不枚举或校验该目录中的候选
- 外部路径仍拒绝 UNC、设备路径、reparse/symlink 和不支持的介质；原生句柄/目录身份和文件身份在选择到登记、登记到使用的边界分别核对
- 现有external来源中的相同物理文件避免双份登记并保留稳定ID；直接选到受控managed原路径时定向核对该manifest并返回原ID，不新建external别名。其他目录中指向managed的硬链接别名不以全库payload扫描寻址；不同目录的同名不同文件可独立存在，不仅按名称判重复
- 手动重扫仅维护默认目录内未作为显式文件来源登记的候选，已有显式项保持来源语义并不重复hash；其他目录显式条目同样原样保留且不读取payload；更换默认目录时旧登记必须保持可访问或明确报告不可用，不静默丢失模型

## 选择、校验与提交

原生选择结果由有时限、单次使用的随机句柄管理；前端只接收文件名/大小和句柄，不获得向后端传任意文件路径的权限。选择取消不开始任何校验。

本片限制每次最多64文件、单文件最多16GiB、所选总量最多32GiB。这些是I/O/登记预算，不保证目标16GB机器可加载同等大小模型。逐文件内容拒绝可形成有界部分成功报告；I/O、身份变化、取消、超时等在提交前中止整批并保留旧索引。提交决定后晚取消不得假报回滚。

登记路径不调用会完整验证所有 managed 模型的 `ModelStore::open`，不枚举或hash未选择文件。允许创建必要私有数据目录/索引与实例锁，但不能为浏览或添加暗中初始化 API 凭据、启动服务/worker。

运行中的实例保持现有模型库所有权；需要用户显式停止后才能添加，不移除 InstanceLock、不隐藏停服或切换模型。保存完成与后续加载/基础测试是不同事实。多选不自动轮流加载所有模型；单个明确目标也仅在用户选择且满足原子空闲条件时测试。

## 默认浏览与维护

默认/下载目录设置使用独立configure-only事务；旧带扫描apply只保留兼容，不作为新UI普通目录设置入口。配置时将旧默认条目固定为显式来源，原子更新目录三元组，失败保旧。

启动、切页、刷新不执行 `discover → scan` 或 `reconcile → full scan`。列表从有界持久化元数据读取，扫描错误不再导致下次启动自动重复全量工作。保留“手动扫描默认目录”入口，明确仅处理未单独添加的候选；已单独添加的文件通过重新添加或实际加载复核，不把该入口称为全库或所有文件的完整重新校验。

这不等于“服务启动永远不读模型”：原 managed 库启动完整性检查、真正加载的文件验证是独立既有环节，不能将取消 UI 自动全扫夸大为取消全部完整性保护。

## 升级与后续

schema2 写入后旧程序不保证可读，应先保存升级前索引/配置备份；不得为旧版本回退静默删掉新字段或链接。这里记录路径是本地私有索引，不上传到网络或放进通用诊断报告。

Windows 数据目录 canonical 路径导致基础测试记录失败，以及高级校验超时/不自动卸载设置，由后续独立切片修复。本片保留当前有界时间控制，最终使用说明须按联合版本的实际配置规则更新，不能预写可调超时已完成。

## 验证要求

必须证明未选文件的payload不被读/hash；跨目录、同名/重复、旧schema、部分内容拒绝、取消、超时/身份/I/O失败、原子保存和服务占用均覆盖。下载后用定向路径，不回退全库扫描。UI取消/重复点击/切页/关闭、无隐式启动或凭据初始化、只读列表与完整维护入口分别验证。Linux逻辑和模拟文件测试不替代Windows原生选择器、写删保护或真实模型验收。
