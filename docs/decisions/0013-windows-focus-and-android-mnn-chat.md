# ADR0013：当前回到Windows，安卓改走MNN Chat修改路线

日期：2026-10-02。状态：按用户最新方向采纳。

## 决策

用户明确需要的是手机运行模型、通过API供其他应用调用，而不是优先重做完整聊天客户端；随后明确要求当前回到Windows，安卓计划通过修改MNN Chat实现。

1. 当前Nexa开发聚焦Windows本地推理runtime、已有HTTP/API与最小桌面模型管理。Windows继续llama.cpp/GGUF，不因Android方向调整重写已验证后端。
2. 独立Android验证器/聊天产品继续开发暂停。已交付的0.1.1研究APK、报告、MNN适配与安全契约作为历史证据保留；B3b未提交WIP不视为产品交付，不再为本轮构建新APK。
3. Android后续修改MNN Chat需独立确定目标仓库、后台服务与API范围。用户本次方向选择不等于已经完成集成、开启局域网、生成长期凭据或增加权限。
4. 先前ADR0009的完整聊天对标排期与T07/T08后续切片作为暂缓方案，不再驱动当前任务；不删除历史设计或把未完成项写成通过。
5. 当前已经发生的共享core故障修复仍需完成Windows回归；已启动Android CI只用于该共享改动的验证收尾，不另开Android产品任务。

## 当前Windows切片

完善模型兼容性可见性与API接入说明，保留精确矩阵准入及external加载时完整性复验。新模型架构/量化支持需要另行锁定资产与真实验收，不能通过放宽UI门槛获得。Windows10优先；Windows11、无开发工具、实际离线和长期稳定性仍按既有后期验证边界处理。
