# ADR0020：显式启用的局域网推理 API

日期：2026-10-04。状态：实现与本地回归完成；Windows 局域网实测及联合交付待验。

## 目标

允许同一可信局域网内的手机和其他电脑调用 Windows Nexa 已加载的文本模型。此为默认关闭的显式增量，不将原来的本机管理接口直接绑定到全网卡，不恢复 Android/Harness 开发，也不开放公网服务。

本轮从最新 main `6167d07cb523cc838e6a6fb082e660d56e9d7f79` 创建 `codex/nexa-lan-api`。后续新功能均从当时最新 main 建独立分支，不沿用旧功能分支。

## 服务与权限边界

1. 原回环监听、实例发现和同连接 HMAC 服务端证明不变；本机 CLI/bridge 继续只认回环地址
2. 新建独立 LAN listener、认证中间件和极小路由，仅开放 `GET /v1/models`、`POST /v1/chat/completions`；不挂载 `/runtime/*`、`/healthz` 或管理能力
3. LAN 使用独立 Bearer 凭据，不能使用本机管理令牌；所有 LAN 路由均须鉴权。凭据不从 query/cookie 获取，不信任 Forwarded/X-Forwarded-For 声称的来源
4. 第一期只允许具体 RFC1918 IPv4 监听地址和非零端口，禁止通配、公网和回环 LAN 配置；客户端名单为 1–16 条规范的私有 IPv4 CIDR，范围 `/24` 至 `/32`，不接受重复、重叠或空名单
5. 校验真实 socket peer/server 与精确数字 Host；默认拒绝携带 Origin 的浏览器请求。不提供任意 CORS 放行、反向代理信任或 DNS 主机名模式
6. LAN 只调用本机已经加载的模型，不能通过 chat 暗中加载或切换其他模型；必须由 actor 原子检查。没有加载模型时列表为空、chat 明确失败；不能用一次 status 查询代替原子条件
7. 共用原单模型、单运行任务、有限 FIFO 和取消/超时资源限制；连接总预算64，LAN最多48，为本机管理保留容量。LAN 请求正文还须有有界读取期限，不能仅限制 header 而允许慢 body 永久占槽
8. LAN 请求 ID 由服务端生成；断开连接取消该请求，不允许通过管理路由取消其他客户端任务。本机仍保留管理、停止和取消入口

## 配置、密钥与生命周期

配置是 `lan_api = { enabled: false, listen: null, allowed_cidrs: [] }`，缺失字段沿用关闭默认值。关闭状态允许无地址/名单，启用时严格验证。设置保存须显式停止服务，不隐藏停止、重启或模型切换；新配置与当前实际监听状态分别展示。

浏览设置、读取快照、离线模型列表及关闭的 LAN 不生成密钥。仅用户已显式保存启用配置并启动服务时创建/读取独立私有 LAN 凭据，复用现有平台私有文件与原子发布规则。只在本机原生端执行用户明确触发的复制；JS、普通 DTO、日志、发现文件和打包报告不得接收密钥。复制失败不得回传密钥作为兜底。

两个监听在 runtime 创建和实例发布前准备；任一失败即启动失败并释放已获得资源。不显示“LAN运行中”却只剩本机服务。关停、监听失败及进程退出必须协调两个 listener、已有连接、runtime 和 worker 清理，不能遗留 LAN 监听或假报停止。

## 传输风险与用户操作

第一片采用 HTTP，Bearer 和对话内容没有 TLS 传输加密，仅适用于可信私有局域网。界面启用前明确风险；不能把私有 IP/CIDR 或 Bearer 认证描述为加密。无需放宽系统证书校验；本片不配置 TLS。

不自动修改 Windows 防火墙、网络类别、路由器端口映射或 NAT。若目标 Windows 拦截连接，由用户在自己的电脑按所需私有网络和客户端范围放行。禁止建议直接关闭防火墙或把监听暴露到公网。

## 验证要求

- 默认关闭与旧 config/CLI/discovery/管理证明兼容
- 非法地址/端口/CIDR，实际来源、Host、Origin、错误/管理凭据、未知管理路由和方法拒绝
- LAN 没有模型时不隐式加载；actor 排队、idle unload、切换/卸载并发下边界仍成立
- 明确区分模型逻辑 fake、模拟 peer、真实 loopback TCP、真实 GGUF 和 Windows 两台设备局域网测试
- SSE/非流式、FIN/RST、慢 body、连接预算、队列、停止/双监听失败与资源释放
- 桌面重复点击/服务运行保存拒绝、设置与实际状态、原生复制结果和明文风险提示
- 最终包完整身份/组件/PE/许可/hash仍按既有规则，禁用 GitHub Actions Rust 构建

认证、配置及单机回归通过不等于已完成 Windows 防火墙、无线网络隔离、目标设备或长期稳定性验收。
