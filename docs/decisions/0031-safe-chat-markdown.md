# ADR0031：聊天回复的安全 Markdown 展示

日期：2026-10-06。状态：开发实现、回归与独立审查完成，原生Windows与交付待验。用户要求聊天页面支持 Markdown；本任务只改变回复展示，不扩展模型能力或系统操作权限。

## 范围

使用官方 React Markdown 语法树渲染组件及 GFM 插件，精确锁定依赖。支持标题、强调、列表、引用、表格、任务列表、删除线、行内代码及围栏代码；不以正则替换 HTML 模拟解析器。流式片段和中断时的未闭合围栏仍应安全显示，完成后继续正常排版。

历史、上下文、请求、复制整条回复均保留原始文本；不会将渲染 HTML 发送给模型或覆盖存档。用户输入继续按原始内容显示。长表格与代码块在局部横向滚动，不撑开应用整体布局。

## 安全与离线

- 不使用 `dangerouslySetInnerHTML`、MDX、原始 HTML 解析或动态脚本执行；模型生成内容不获得应用权限
- 不加载远程图片、iframe、字体、样式等资源；Markdown 图片显示说明占位，避免只浏览对话就联网
- 链接保持可读、可复制，不直接导航当前 WebView，不新增通用 shell/open-url 权限；危险协议不成为可执行链接
- 代码块仅展示与复制，不执行命令。数学公式、Mermaid、任意 HTML 和语法高亮扩展不属于本轮承诺
- 解析或展示异常由单条消息边界隔离并回退纯文本，仍可复制原文；不得因为深嵌套回复让整个会话页面崩溃，不将回复正文写入诊断
- 新依赖纳入现有许可证收集和无损打包流程，不通过删除许可证压低文件数

## 验证

覆盖普通语法、表格/任务列表、分片围栏、流式终止、多条消息、原文复制、长内容及恶意 HTML/URL/图片。重新运行前端全量 test/typecheck/lint/build、依赖审计及打包许可回归。测试 DOM 与真实 Windows 窗口分别记录，不将模拟 DOM 当作目标机视觉验收。

参考：[react-markdown](https://github.com/remarkjs/react-markdown)、[remark-gfm](https://github.com/remarkjs/remark-gfm)。
