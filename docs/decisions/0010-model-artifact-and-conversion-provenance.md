# ADR0010：区分可复现运行资产与可复现模型转换

日期：2026-10-02。状态：已采纳工程决策；不授予当前候选生产支持。

## 背景

Android产品需要兼容MNN Chat使用的公开模型生态。已锁定的[公开预转换Qwen3-0.6B资产](https://huggingface.co/taobao-mnn/Qwen3-0.6B-MNN/tree/34dfccda1187ded6e07ea06426da576b0b793c6b)缺少精确exporter commit与原始Qwen revision。固定发行资产的字节可重复获取，不等于能够从原始模型重复生成相同资产；换用当前导出器也不能补造历史身份或保证格式一致。

## 决策：两条资产路径

| 路径 | 必需证据 | 可以声明 / 不可声明 |
| --- | --- | --- |
| 可信公开预转换资产 | 发布者、公开来源与许可；精确仓库revision、完整文件闭包/逐文件及包hash、模板/tokenizer身份；不可变受控包；对应runtime/后端/设备与安全测试 | 可申请该精确运行资产组合的准入；exporter/原始revision未知须显式记录，不能宣称转换可复现 |
| 自行导出/转换资产 | 上述运行资产证据，另锁原始模型revision/许可、exporter完整commit/补丁、转换/量化/校准参数、工具依赖及产物身份，并验证转换流程 | 可在证据范围内声明可重复转换；不能仅凭文件相同名称继承其他包的支持结论 |

自行导出是自定义模型/量化或要求可重复转换时的能力，不是所有模型目录条目的强制入口。导出器与原模型revision未知**本身**不阻塞预转换路径的T07-A运行基线；不降低真实Android运行、生产安全或发行许可门槛。自导出的QNN/Hexagon目标图仍需锁定其工具链和转换身份；若采用预转换目标图，也须验证目标SoC/架构、runtime兼容与实际设备行为。

## 不变的安全边界

- “可信发布者”是来源资格，不是执行其配置/代码的授权。不执行模型附带脚本/原生代码，不允许任意URL下载，不透传未知配置
- 两条路径都必须做文件引用闭包、路径/hash/schema验证、不可变导入及受控运行配置，保持模型包与缓存隔离；不能因上游App能打开而豁免Nexa检查
- 模型来源、转换来源与已验证运行组合分别记录；缺失值明确unknown，禁止推断或伪造
- 未获验证的新模型、资产变体、runtime/后端或设备不继承旧支持；不因这项技术决策新增账号、数据上传或下载权限

## 当前候选与迁移

当前五文件候选运行输入已有精确revision/hash；走公开预转换路径，原始Qwen revision/exporter commit继续标未知，不修改旧资产，不为补齐身份强制重新转换。生产store/闭包schema、MnnExecutor、采样/安全取消、设备与许可/发行门槛仍未完成，因此仍不是生产准入包；T07-A继续等待真实Android运行证据。

本决策收窄旧规范中“所有模型必须锁导出器/原始revision”的通用要求：它对自导出路径保持强制，对预转换路径改为如实记录已知/未知来源。与本决策冲突的旧方向描述按此解释；产品阶段与通用runtime边界保持。
