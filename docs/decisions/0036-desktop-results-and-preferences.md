# ADR0036：桌面结果归档与工作区设置持久化

2026-10-08，已采纳。任务 W02-PERF-2 / W02-OCR-5 / W02-PREF-1。用户要求性能摘要位于输出下方、保留最近100条OCR结果、重启恢复参数及提示词，并明确配置继续使用TOML。

## 配置归属

运行策略、全局推理默认值及模型档案仍归现有 `config.toml`，沿用显式保存、CAS与生效范围。桌面新增固定私有 `workbench-preferences.toml`，schema 1，存储OCR模型选择、上下文/线程/批次草稿、最大输出token、提示词、图片缩放与原文/Markdown视图，以及未发送的聊天草稿。既有 `desktop-settings.json` 的关闭策略等历史结构不在本次迁移范围。

文件最多64KiB，OCR提示词最多4096 UTF-8字节，聊天草稿最多16KiB；超限保留界面输入并明确未保存，不静默裁切。模型草稿最多128组，各存已保存档案基线base与本窗口draft。再次选择模型时核对当前已保存有效参数：无编辑跟随档案；基线未变恢复草稿；档案与草稿均变化则显示冲突，由用户选择，不静默覆写任一方。模型ID不是文件hash，不表示相同权重。

先读取后启用编辑与自动保存，不能用初始默认值抢先覆盖磁盘。有效改动合并为400ms延迟写入，正文Unicode保持；串行CAS依据原文件SHA-256 revision。读取错误/损坏文件不退回默认再保存，冲突不自动重试覆盖；提供重读、明确保留当前输入后覆盖或重试。加载模型仍是显式动作，恢复参数不自动加载或发起推理。

## OCR结果数据

归档是用户明确授权的桌面结果数据，不是日志或runtime会话数据库。固定私有 `ocr-history.json` 使用JSON保存有界列表；配置采用TOML的要求不把长篇识别正文混入运行配置。最多100条，按首次保存时间最新优先，新增第101条移除最旧条目；同ID重复创建不改变排序。每条原文最多256KiB，编码文件最多32MiB，超限拒绝并保留原文件，不静默裁切正文。

保存请求UUID、图片文件名（无路径）、模型ID、首次保存时间、终态/截断标记、原始Markdown，以及可选的匹配性能记录。不保存原图或提示词，也不联网同步。取消/失败有非空正文时保存为不完整；空正文不创建。文本先保存，性能查询稍后补写；补写必须匹配原内容与元数据，删除后迟到更新不得重新创建记录。

历史页提供查看、原文/Markdown切换、复制、另存.md和删除。会话聊天正文仍不持久化；仅未发送草稿记忆。runtime最近200条性能记录仍是内存中的无正文元数据，退出清空，与这100条桌面OCR归档分开。

## 输出性能与关闭顺序

桌面 `ChatBatch` 增加可缺省 `runtime_instance_id`，来自生成请求同一已验证连接。终态后的单次性能查询须核对实例、唯一request_id、模型、类型、状态、输出预算以及成功usage/finish_reason；不一致或不可用只显示指标不可用，不影响正文或将另一请求指标附到当前结果。摘要放在输出下方，不混入复制或.md原文。

正常关闭先确认未保存的配置草稿、完成本窗口任务清理和已登记写入，再调用原生关闭。标题栏及退出事件通过固定本地CustomEvent与nonce ACK转入同一前端保存流程；ACK只代表收到事件，不表示同意退出。5秒无响应使nonce过期，再提供原生重试/保留窗口/明确可能丢失内容后关闭，迟到ACK不能触发关闭。等待期间不提前阻断保存命令。

两个存储各自持有跨进程文件锁，读写使用同一锁，私有文件检查、原子替换和严格schema/大小校验；损坏文件保留。bridge关闭等待在后台线程中实际执行的写入许可，再清理运行资源。不增加任意路径读写、通用event/fs/shell或LAN管理能力。新增命令仅授予可信main窗口。

实现与验证级别见[本轮验证](../verification/2026-10-08-output-history-and-preferences.md)，Windows原生窗口及用户设备仍独立待验。
