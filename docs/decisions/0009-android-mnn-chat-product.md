# ADR0009：Android 应用能力对标 MNN Chat

日期：2026-10-02。状态：已采纳产品方向；实现/验收按阶段记录。

## 决策

Android 最终目标由最小推理验证客户端升级为 MNN Chat 级本地 AI 应用，关注能力与可用性，不要求复制 UI。Windows 现有交付、MNN 主引擎和通用 Rust 控制层方向保持。

[产品计划](../android-app-parity.md)维护固定参考、能力矩阵和阶段门槛。先打通安全 CPU 基础，再交付具有模型目录/下载/导入/存储、多会话历史、设置与诊断的文本 APK；视觉、音频、语音、生图及加速分阶段准入。内部 native 探针或最小验证页不等于日常可用 APK，也不等于全量对齐。

## 边界

- App 管理目录网络、下载状态、聊天/附件持久化、呈现与权限；runtime 只提供版本化能力、资产准入和有界任务控制，不引入聊天数据库、账号或市场业务
- 多会话不扩展成多模型并行；保持单运行槽、精确预算、取消/唯一终态和 Android 后台安全卸载
- 多模态需新增受控输入输出/预算与模型资产闭包，不能宣称现有文本协议已兼容
- 不因对标自动增加云账号、云同步、后台常驻、Android网络API、遥测或排行榜上传；这些需单独范围决策
- 不承诺全部模型、全部后端或特定吞吐；按模型/量化/模板/后端/设备组合留证

## 对旧约定的影响

替代 AGENTS、架构、执行规格、T08和Android计划中“移动仅最小验证UI”“App无持久化历史”“无模型目录”作为最终产品边界的表述。文本-only与非思考模式仍可作为CPU第一阶段约束；runtime不保存聊天历史继续有效。ADR0001/0008保留历史与不冲突部分。第一版可用APK与后续阶段验收不追溯修改Windows已有通过结论。
