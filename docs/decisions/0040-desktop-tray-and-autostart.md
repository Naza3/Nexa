# ADR0040：可选关闭到托盘与当前用户开机启动

状态：已采纳，2026-10-08。源码与验证状态分别见当前状态和本轮验证记录。

## 决定

设置页提供独立的“关闭到托盘”和“开机启动”，两项默认关闭。开启其中一项不会改变另一项；登录启动显示主窗口，不新增静默启动或自动加载模型策略。

关闭到托盘保存于既有 `workbench-preferences.toml` 的 `close_to_tray`，沿用原子替换、文件锁与版本冲突检查。旧文件缺少此字段时默认 false。标题栏关闭读取已保存偏好；启用后仅隐藏窗口，继续任务、服务和已加载模型。托盘入口创建失败或设置读取失败时保留窗口并提示，不让应用失去操作入口。

托盘提供“显示 Nexa”“退出 Nexa”，左键图标恢复窗口。真正退出沿用正文/草稿保存、请求终态与清理握手；失败恢复窗口。既有 `close_runtime_on_exit` 只在真正退出时决定是否停止服务，隐藏窗口不执行该策略。隐藏、恢复与退出间的异步竞态通过代次检查处理。

开机启动使用固定 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\Nexa`，值为带引号的当前 EXE 路径，无额外参数，不需管理员权限。界面读取系统实际登记值，修改后回读确认；错误不展示为成功。完整命令遵守 Windows Run 的 260 字符限制；便携目录过深时提示移动到更短路径。

Windows 的启动应用管理也可独立禁用此项，界面说明“已登记”不等于系统保证执行。此系统集成以注册表为持久化来源，不在 TOML 再维护一份可能与系统设置冲突的开关。其他已有模型参数、提示词与界面设置仍保持 TOML。

## 安装与卸载

安装默认不登记开机启动；同格式覆盖/升级保留已有启动选择。正常卸载只删除精确指向该安装目录的 Run 值，不删除共享键、其他位置的 Nexa 或用户数据；MSI 在提交卸载时清理且排除升级过程，NSIS 排除 `/UPDATE`。详见 [ADR0039](0039-tauri-windows-installers.md)。

## 验证边界

Linux 单测、Windows 交叉编译与原生 Windows 执行分开记录。目标 Windows 10 的托盘交互、任务持续运行、登录自动启动、系统禁用启动项与安装升级/卸载需实机验证；交叉构建成功不替代这些行为。
