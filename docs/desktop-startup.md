# 托盘与开机启动

在 Nexa 左侧进入“设置”，可以分别控制以下两项；默认都关闭。

## 关闭到托盘

1. 打开“关闭到托盘”开关，等待界面显示设置已保存。
2. 点击窗口右上角的 ×。窗口隐藏，当前 OCR/聊天任务、运行服务和已加载模型继续保留。
3. 在 Windows 通知区域单击 Nexa 图标，或右键选择“显示 Nexa”恢复窗口。图标可能收在通知区域的上箭头菜单内。
4. 要真正退出，右键托盘图标选择“退出 Nexa”，或使用界面的退出按钮。应用先保存设置和已有识别结果，再按“关闭窗口时同时退出运行服务”的偏好处理服务。

关闭到托盘保存在 `workbench-preferences.toml`，重启后保持。开关关闭时，标题栏 × 沿用原来的退出行为。若托盘创建失败，应用会保留窗口并提示。

## 开机启动

1. 打开“开机启动”开关，确认下方显示“已登记当前用户的登录启动项”。
2. 下次该 Windows 用户登录后，Nexa 自动打开主窗口。开机启动不会自动开启关闭到托盘，也不额外启用模型自动加载。
3. 要取消，在同一处关闭开关并确认“未登记开机启动项”。

启动项使用 Windows 当前用户注册表，无需管理员权限，退出或重启应用后仍保留。该开关读取系统登记状态；其他模型参数、提示词及界面偏好仍使用 TOML。

Windows“任务管理器 → 启动”或“设置 → 应用 → 启动”也能单独禁用应用。因此已经登记但未自动打开时，请同时检查系统中的 Nexa 是否被禁用。便携版移动目录后，在此处选择“更新为当前 Nexa”；路径过长时请先移动至更短目录再开启。

同格式安装升级会保留设置。正常卸载会移除指向该安装目录的启动项，保留模型、配置、历史结果及其他位置的启动项。MSI/NSIS 的选择和旧版本更新步骤见[安装器说明](windows-installers.md)。
